🎯 NEXT STEPS TO USE:

1. Open project in Android Studio
   → File → Open → Select droneRelayAppV2 folder

2. Get DJI API Key
   → Visit https://developer.dji.com/user/apps/
   → Create app with package name: com.pixel.dronerelayapp
   → Copy your API key

3. Add API Key to app
   → Open app/src/main/AndroidManifest.xml
   → Line 47: Replace PLEASE_ADD_YOUR_API_KEY_HERE with your key
   → Save file

4. Build and Install
   → Connect Android phone via USB
   → Enable USB Debugging in phone settings
   → Click Run button (▶️) in Android Studio
   → Wait for installation

5. Test with Hardware
   → Power on DJI Mini 4 Pro
   → Power on DJI RC-N2 controller
   → Connect phone to RC-N2 via USB
   → Grant USB permission when prompted
   → App should show "Connected"

⚠️ IMPORTANT NOTES:

1. API KEY REQUIRED: You MUST add your DJI API key in AndroidManifest.xml
   The app will not work without it!

2. INTERNET REQUIRED: First-time SDK registration requires internet connection

3. RC-N2 ONLY: DJI Mini 4 Pro requires RC-N2 controller (not RC 2)

4. USB CABLE: Use a good quality USB OTG data cable (not charge-only)

5. PERMISSIONS: Grant all permissions when prompted for full functionality

6. FIRMWARE: Keep drone and controller firmware up to date
